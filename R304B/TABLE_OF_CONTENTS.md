## What this document is for

USNRC Technical Training Center (HRTD) re-issue of the General Electric **Systems Technology Manual**. It is the single best systems-level description of the **BWR/3 and BWR/5** balance of plant and nuclear steam supply system: what each system does, how it is laid out, how components work, how systems interact, and what the operator sees. Written for reactor operator licence training, so it explains purpose → description → components → features → interfaces → summary for every system.

**Use it for:**

- Explaining how a BWR system works end-to-end (e.g. recirculation, RCIC, HPCI, ADS, RHR).
- BWR/3 vs BWR/5 component and design differences (jet pumps, CRD, containment, ECCS).
- Operator-level questions: indications, setpoints, interlocks, failure modes, surveillance.
- Anatomy of components (recirculation pump seals, jet pumps, MSIVs, SRVs, control rod drives).

> **Note:** Chapter numbering follows the GE manual; sections 1.1–1.6 were not in the source set.
