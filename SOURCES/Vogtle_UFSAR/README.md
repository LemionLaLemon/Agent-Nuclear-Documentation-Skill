## Notes on this edition

- **Page numbers refer to positions in the merged PDF, not the FSAR's printed page numbers.**
  The printed headers (e.g. `VEGP-FSAR-9 9.2-14 REV 18 9/13`) are preserved inside each file
  and are the authoritative citation. Page ranges here are continuous and non-overlapping.
- **The NRC package label for `ML17032A139` is wrong.** It is described as "Section 15.2", but the
  file actually begins at Figure 6.2.1-22 (Sheet 1 of 74), a steam-generator inlet-elbow figure,
  and runs through Figure 7.6.4-1. It sits in the correct sequence between the Chapter 6 and
  Chapter 7 parts. A page-level comparison against `ML17032A143` ("Section 15.2, Redacted")
  found no overlap: there is **one** copy of §15.2, not two.
- **Chapters 16 and 17 are not part of this package.** The Technical Requirements Manual and the
  Improved Technical Specifications Bases are supplied instead, as in the NRC posting.
- **9,340 pages vs 9,464 stated by the NRC index.** The 124-page difference is the index claiming
  732 pages for `ML17032A139` when the file has 606, offset by +2 pages in one drawing part.
  Every file downloads and opens cleanly; no page is missing at a chapter boundary.
- Vogtle **3 & 4** are AP1000s (dockets `05200025` / `05200026`) and are **not** covered here;
  they are a different design and a different UFSAR.

## Rebuilding the single PDF

```bash
python3 - <<'EOF'
import glob, pymupdf
out = pymupdf.open()
for f in sorted(glob.glob("SOURCES/Vogtle_UFSAR/*.pdf")):
    out.insert_pdf(pymupdf.open(f))
out.save("Vogtle_UFSAR_Rev20.pdf", garbage=4, deflate=True)
EOF
```

Sorting is lexicographic over the names above, which is document order; `chapter-03` and
`reference-drawings` carry `_partNofM` suffixes for that reason.
